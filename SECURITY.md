# Security Policy

## Reporting Security Vulnerabilities

If you believe you have found a security vulnerability in Disambiguator, please do **not** open a public issue.

Instead, report it privately via:
- **GitHub Private Vulnerability Reporting** via the repository's **Security** tab.
- **Email:** `agus.monetti01@gmail.com` with the subject `[SECURITY] Disambiguator`.

Please provide:
- A description of the issue and potential impact.
- Steps to reproduce or a minimal proof of concept.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible resolution.
